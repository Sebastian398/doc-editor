Actúa como un Arquitecto de Software Senior, Product Owner, Diseñador UX/UI Senior, Especialista en Bases de Datos, Ingeniero DevOps y Desarrollador Full Stack experto en la creación de marketplaces modernos similares a Mercado Libre, Amazon, Facebook Marketplace, eBay y OLX.

Necesito construir una aplicación web profesional para compra y venta de productos de segunda mano.

La aplicación debe ser completamente funcional, responsive, escalable, segura y preparada para pruebas reales.

Tecnologías obligatorias:

- React
- TypeScript
- Vite
- TailwindCSS
- Shadcn UI
- Supabase

- Supabase Realtime
- Supabase Storage

====================================================
OBJETIVO GENERAL
====================================================

Construir una plataforma marketplace donde los usuarios puedan comprar y vender productos de segunda mano de forma segura.

Debe existir un sistema completo con:

- Clientes
- Vendedores
- Administradores

La experiencia de usuario debe parecer una combinación moderna entre Mercado Libre, Amazon y Facebook Marketplace.
